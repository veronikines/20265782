# LOQUEPINT3D

## Descripción
LOQUEPINT3D es una página web dedicada a mostrar productos impresos en 3D, como llaveros, macetas decorativas y figuras personalizadas.

## Tecnologías utilizadas
- HTML5
- CSS3
- Google Fonts
- Formspree para el formulario de contacto

## Características
- Navegación entre secciones.
- Catálogo de productos con imágenes y precios.
- Sección de reseñas.
- Formulario de contacto .


## Objetivo
Este proyecto fue desarrollado como parte de la pre-entrega del curso de Front-End, aplicando los conocimientos adquiridos en HTML y CSS.
